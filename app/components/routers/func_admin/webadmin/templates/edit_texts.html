Важно: Поддержка HTML-тегов
Поддерживаемые теги:
  • <b>текст</b> — жирный текст
  • <i>текст</i> — курсив
  • <u>текст</u> — подчеркнутый текст
  • <s>текст</s> — зачеркнутый текст
  • <a href="url">ссылка</a> — гиперссылка
  • <br> — перенос строки
Примеры:

Исходный код:

<b>Важно!</b> Это <i>очень</i> важное сообщение.<br>Переходите по <a href="https://example.com">ссылке</a>.

Результат:

Важно! Это очень важное сообщение.
Переходите по ссылке.
Важное замечание: Все HTML-теги будут автоматически обработаны. Неправильное использование тегов может нарушить отображение текста и приведет к перезапуску бота, перед сохранением обязательно просмотрите предпросмотр текста.
Для переноса строки используйте клавишу Enter.
